# 资金管理系统

面向个人与家庭的轻量级财务管理 Web 应用。

## 功能

- **总览**：总资产、本月收入/支出/结余、近 6 个月趋势、账户余额、最近流水
- **流水**：收入、支出、转账记录，支持删除并自动回滚余额
- **账户**：多账户（现金、银行、电子钱包等）与初始余额
- **报表**：按月支出/收入分类、储蓄率、收支对比图
- **设置**：自定义分类、恢复演示数据、本地持久化

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5173>。

## 技术栈

React 18、TypeScript、Vite、Tailwind CSS、Recharts、localStorage
